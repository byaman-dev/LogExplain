# 📖 Purpose

This roadmap outlines the planned direction of LogExplain.

It highlights the project's long-term vision while keeping Version **0.1** intentionally focused and achievable.

Roadmaps evolve over time. Priorities may change as the project grows and community feedback is incorporated.

---

# 🎯 Long-Term Vision

LogExplain aims to become a trusted educational platform that helps beginners understand security events through reasoning, investigation, and practical guidance.

The project begins with a command-line interface, but the knowledge base is designed to support multiple interfaces in the future.

---

# 🚀 Version 0.1 — Foundation

**Goal:** Build a simple, maintainable foundation for the project.

### Core Application

* Command-line interface using Typer
* Rich terminal output
* Markdown-based knowledge base
* YAML front matter
* Pydantic validation

### Knowledge Base

* Initial Windows Security Event documentation
* Consistent educational structure
* Contributor-friendly Markdown format

### Project Quality

* Documentation
* Automated testing
* GitHub Actions
* Community guidelines

**Status:** 🚧 In Development

---

# 🌱 Version 0.2 — Growth

**Goal:** Expand educational content while improving the contributor experience.

### Planned Improvements

* Additional Windows Security Events
* Improved CLI usability
* Better search and navigation
* Expanded educational content
* Improved test coverage

**Status:** 🔮 Planned

# 🌍 Future Direction

As the project matures, LogExplain may expand beyond Windows Security Events.

Potential areas include:

* 🐧 Linux authentication logs
* 🌐 Apache and Nginx logs
* 🔥 Firewall logs
* ☁️ Cloud security events
* 🛡 MITRE ATT&CK references
* 🚨 Detection engineering concepts
* 🔍 Incident response guidance

These initiatives are long-term goals rather than commitments for the next release.

---

# 🖥 Future Interfaces

The knowledge base is designed to support multiple interfaces without duplicating educational content.

Possible interfaces include:

* 💻 Desktop Application
* 🌐 Website
* 📱 Mobile Application
* 🧩 VS Code Extension
* 🔌 REST API

The command-line application will remain the primary interface for Version **0.1**.

---

# 🤝 Community Goals

Beyond new features, the project aims to grow a welcoming and collaborative open-source community.

Long-term goals include:

* High-quality educational content
* Beginner-friendly contribution process
* Consistent documentation
* Reliable code quality
* Sustainable project maintenance

---

# 📌 Guiding Principles

When deciding what to build next, the following questions guide development:

* Does this help beginners understand security events?
* Does this improve educational quality?
* Does this keep the project simple and maintainable?
* Does this support the long-term vision of the knowledge base?

If the answer is **no**, the feature probably does not belong in LogExplain.
