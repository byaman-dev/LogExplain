# 📖 Overview

Understanding security logs is one of the most important skills in cybersecurity, yet it is often one of the most challenging for beginners.

Most documentation explains **what** happened.

Experienced analysts naturally ask additional questions:

* Why did this happen?
* Should I worry?
* What evidence should I investigate?
* What should I do next?
* What questions should I ask before drawing conclusions?

Developing this investigative mindset takes time and experience.

LogExplain was created to bridge this learning gap.

Rather than encouraging users to memorise Event IDs or log formats, LogExplain teaches how to interpret security events through reasoning, investigation, and practical guidance.

The project combines a structured Markdown knowledge base with a lightweight command-line interface to deliver consistent educational content that can grow with the cybersecurity community.

---

# ❓ The Problem

Security professionals regularly work with logs generated by operating systems, applications, network devices, and cloud platforms.

Beginners often encounter logs such as:

* Windows Security Event IDs
* Linux authentication logs
* Apache logs
* Nginx logs
* Cloud security events

Learning resources usually stop after explaining the meaning of an event.

However, understanding **what happened** is only the beginning.

Experienced analysts investigate the surrounding context, evaluate potential risk, correlate additional evidence, and determine appropriate next steps.

LogExplain focuses on developing this investigative way of thinking.

---

# 🎯 Project Objectives

The goals of LogExplain are to:

* Teach reasoning instead of memorisation.
* Help beginners understand security events with confidence.
* Encourage structured investigation.
* Provide practical guidance for common security events.
* Build a community-driven educational knowledge base.
* Remain simple, maintainable, and easy to contribute to.

---

# 🧠 Educational Philosophy

LogExplain is designed to feel like an experienced Security Operations Center (SOC) analyst mentoring someone who is beginning their cybersecurity journey.

Every explanation should answer the following questions:

1. What happened?
2. Why did it happen?
3. Should I worry?
4. Why should I care?
5. What can I do?
6. Where should I investigate?
7. Think Like an Analyst
8. Learn More

This framework is the foundation of every explanation within the project.

---

# 🌱 Core Principles

The project is guided by a few simple principles.

### Education First

Technology supports the learning experience—it does not define it.

### Teach Reasoning

Understanding why an event matters is more valuable than memorising an Event ID.

### Keep It Simple

Version 0.1 intentionally focuses on a small, high-quality foundation instead of a large feature set.

### The Knowledge Base Comes First

The Markdown knowledge base is the project's most valuable asset.

Everything else exists to make that knowledge easier to access.

# 🚫 What LogExplain Is Not

LogExplain is **not**:

* A SIEM
* A log management platform
* A security monitoring solution
* An AI chatbot
* Another Event ID database

The project is educational first.

The knowledge base is the product.

The command-line application is simply the first interface.

# ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/byaman-dev/LogExplain.git
```

Move into the project directory:

```bash
cd LogExplain
```

Install the project:


# 📚 Knowledge Base

The knowledge base is the heart of LogExplain.

Each security event exists as an individual Markdown document with structured YAML front matter.

Example:

```text
knowledge/
└── windows/
    ├── 4624.md
    ├── 4625.md
    └── 4688.md
```

This structure allows contributors to improve educational content without modifying the Python application.
